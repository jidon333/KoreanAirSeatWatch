# Korean Air Seat Watch

대한항공 공식 웹 화면을 사용하는 Windows 마일리지 좌석 조회·알림 도구입니다. 대한항공과 제휴한 공식 앱은 아닙니다. 항공편 예약·대기 신청·결제는 수행하지 않습니다.

## 설치와 실행

Windows, Python 3.12, Google Chrome이 필요합니다.

```powershell
.\Setup.ps1
.\Start-SeatWatch.cmd
```

출발·도착 공항 코드, 출발일, 좌석 등급을 입력한 뒤 **지금 조회**를 누릅니다. 로그인은 앱이 연 대한항공 공식 창에서 합니다. 비밀번호는 앱에 입력하지 않습니다. 전용 Chrome을 닫았으면 다음 조회에서 다시 엽니다.

현재 지원: 편도, 로그인한 회원 1명, 한 조건. 가까운 날짜 함께 조회를 항상 체크하고 입력한 날짜의 실제 항공편을 확인합니다. 오류를 매진으로 처리하지 않고 마지막 정상 결과와 확인 시각을 유지합니다.

**15분마다 확인**은 앱 실행 중 같은 조건을 반복하며 새 좌석을 화면과 알림음으로 알립니다. 로그인 만료·접근 거부·확인 불가능한 화면은 감시를 중지합니다. 앱 종료 시 자동 확인이 끝나며 진행 중 조회는 마무리될 수 있습니다. 조회 시 전용 브라우저가 앞으로 나올 수 있습니다.

## 개발 상태

실제 항공편 조회, 입력 변경, 브라우저 종료 후 재실행을 검증했습니다. 로그인 만료 복구, 텔레그램 연결, 장시간 연속 운전 검증을 진행 중입니다. 날짜 범위·여러 조건·가족 탑승객은 아직 지원하지 않습니다.

## 로컬 데이터

- `data/`: 전용 Chrome 로그인 프로필, 개인 설정, 마지막 정상 결과. Git에 포함하지 않습니다.
- `work/`: 개발 진단과 실행 상태. Git에 포함하지 않습니다.
- 브라우저는 `127.0.0.1:9335`에만 디버깅 연결을 엽니다.
- 일반 Chrome의 인증정보를 복사하거나 브라우저 보안 설정을 변경하지 않습니다.
- 진단은 허용한 검색 업무 필드만 기록하며 인증 헤더·쿠키·회원정보를 제외합니다.

## 테스트

```powershell
.\.runtime\Scripts\python.exe -m unittest discover -s tests -v
```

테스트에는 로컬 브라우저와 Windows UI 확인이 포함됩니다. 실제 대한항공 조회는 자동 테스트와 별도로 검증합니다. 접근 거부가 발생하면 요청을 자동 반복하지 않습니다.
